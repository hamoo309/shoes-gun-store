# SHOES GUN — المشروع الرئيسي المعتمد

هذا المجلد هو مصدر المشروع الوحيد للتعديل والبناء والتشغيل. يضم واجهة Next.js، وAPI باستخدام Express، ولوحة الإدارة، وPrisma Schema وMigrations، وأدوات التشغيل والنقل. التشغيل مستقل عن نسخ المشروع الأخرى.

## التشغيل على الجهاز الحالي

افتح هذا المجلد نفسه في VS Code، وافتح Terminal داخله:

```powershell
npm.cmd run local
```

أو اضغط مرتين على `START-SHOES-GUN.cmd`. المتجر على `http://localhost:3000` ولوحة الإدارة على `http://localhost:3000/admin`. اترك نافذة التشغيل مفتوحة. شغّل الأمر مجددًا بعد فتح الجهاز؛ الحسابات والطلبات والمخزون محفوظة.

المتطلبات الخارجية: Node.js 22.12 أو أحدث، وPostgreSQL 16. مكان الأدوات يحدد بـ`PG_BIN` عند اختلاف مسار التثبيت.

## البيانات الخاصة

- `.env`: إعدادات المتجر الأصلية، محفوظة دون تغيير.
- `.local/postgres/`: قاعدة المتجر المحلية المحفوظة.
- `storage/products/`: صور المنتجات المرفوعة.
- `storage/private/`: المرفقات الخاصة إن وجدت.

هذه البيانات مستبعدة من Git ومن حزمة المصدر العامة. لا تحتاج تشغيل `setup` أو `db:seed` أو إنشاء أدمن جديد لمتجر قائم. التشغيل المعتاد يستخدم القاعدة المحفوظة ولا يطبق Migrations تلقائيًا.

## إصلاح الاعتماديات والبناء

بعد إيقاف تطبيق المتجر، من هذا المجلد:

```powershell
npm.cmd ci --include=dev
npm.cmd run db:generate
npm.cmd run build
npm.cmd run local
```

لا تنقل `node_modules` من نسخة أخرى؛ يحتوي روابط Workspaces مرتبطة بمكانه. أمر `dev` للتطوير، و`local` لتشغيل البناء المحلي المحفوظ، و`start` لخادم مجهز بإعدادات الإنتاج الآمنة.

## الاختبارات

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
```

`lint` هنا فحص TypeScript للأنواع والاستيرادات والمتغيرات المحلية غير المستخدمة؛ ليس ESLint أو فحص React Hooks. `npm test` أصبح يشغل اختبارات الأمان وحواجز التشغيل الآمنة. ملفات الاختبار التاريخية محفوظة للمراجعة، ومشغل Seed التاريخي لا يُستدعى تلقائيًا.

اختبارات الدخول المتقدمة وترتيب الرئيسية والشحن تتطلب نسخة مستعادة معزولة وعلامة ملكية `.local/isolated-test.json`. ترفض قاعدة المتجر ومنافذها، وتتحقق من PostgreSQL ومسار البيانات وملكية HTTP قبل أي تعديل. راجع [دليل التشغيل والنشر](docs/RUN-AND-DEPLOY.md).

## النقل والنشر

- للنقل الكامل استخدم أحدث `SHOES-GUN-FULL-TRANSFER.zip`؛ فكّه في مكان جديد وشغّل `RESTORE-FIRST.cmd` مرة، ثم `START-SHOES-GUN.cmd` في المرات التالية. [تعليمات النقل](README-TRANSFER.md).
- حزمة `SHOES-GUN-SOURCE.zip` تحتوي المصدر فقط؛ قاعدة البيانات والإعدادات والصور المرفوعة ليست فيها.
- الواجهة المنشورة على Vercel تحتاج خدمة API وقاعدة PostgreSQL وتخزين صور دائمًا. إعدادات البانر والفوتر تأتي من قاعدة البيانات. راجع [دليل التشغيل والنشر](docs/RUN-AND-DEPLOY.md) و[تفاصيل الإنتاج](docs/DEPLOYMENT.md).
