## الحدود التشغيلية المقصودة

- **InstaPay تحويل يدوي.** لا يتحقق الموقع من الحساب البنكي تلقائيًا، ولا ينفذ تحويلًا أو استردادًا ماليًا. مسؤول المتجر يتحقق من وصول المبلغ ثم يسجّل التأكيد أو الرفض؛ يسجّل رد المبلغ بعد تنفيذه خارج الموقع. الإثبات لا يكفي لإعلان Paid.
- **الإثباتات صور فقط.** JPEG وPNG وWebP بحد 5 MB، مع إعادة ترميز وتخزين خاص. ملفات PDF غير مدعومة. رابط العميل الخاص لا يمنح وصولًا عامًا إلى الصورة؛ عرض الإثبات للمسؤول عبر API محمية.
- **الحجز مستمر حتى المعالجة.** يُحجز المخزون عند إنشاء الطلب. الطلبات غير المكتملة أو Pending Verification تحتاج مراجعة وإلغاء يدويًا عند اللزوم؛ لا توجد مهمة مجدولة لفك الحجز تلقائيًا.
- **الحسابات إدارية وليست ربطًا محاسبيًا خارجيًا.** التقرير يعتمد على التسليم والتحصيل والمرتجعات والمصروفات التي سجلها المسؤول. لا يوجد تكامل مع شركة شحن أو بنك أو برنامج محاسبة أو إرسال SMS/Email تلقائي. تتوفر روابط الطلب وWhatsApp وCSV كما طلب المستخدم.
- **الصلاحيات أساسية.** دور المالك `SUPER_ADMIN` يدير حسابات المسؤولين وسجل التدقيق؛ دور `MANAGER` ينفّذ العمليات اليومية المتاحة. ليست مصفوفة صلاحيات مخصصة لكل زر. يُمنع تعطيل آخر مالك نشط.
- **التكاليف الناقصة تظهر كتحذير.** نقص تكلفة تاريخية يجعل الربح غير مكتمل. تعديل تكلفة المنتج الحالي لا يصلح Snapshot قديمًا تلقائيًا، حفاظًا على التاريخ المحاسبي.
- **دومين الإنتاج يحتاج إعادة بناء.** `NEXT_PUBLIC_SITE_URL` له الأولوية على `siteUrl` في إعدادات قاعدة البيانات؛ ضبط قيمته للنطاق النهائي ثم إعادة البناء يوحّد Canonical وSitemap وStructured Data. عناوين API الداخلية ليست عنوان المتجر العام.
- **الاستضافة لم تُنفّذ للعامة.** التطبيق يحتاج Node.js وPostgreSQL وتخزينًا دائمًا. ملفات Docker وCaddy جاهزة للتحقق على المضيف، ولم تُشغّل Docker في جهاز التطوير لعدم توفره. لا يمكن نشر هذا الـBackend كصفحات ثابتة فقط في Sites.
- **صور وبيانات التطوير للتجربة.** الصور مأخوذة من المرجع الذي قدّمه المستخدم؛ لا تمثل إثبات ملكية تجارية أو مخزونًا حقيقيًا. يجب اعتماد حقوق الصور والمنتجات وأسعار الشحن والتكاليف والسياسات قبل استقبال طلبات حقيقية.
- **التحقق النهائي مرتبط بسجل الاختبارات.** اجتازت 26 حالة تكامل قاعدة PostgreSQL المعزولة. نتيجة البناء النهائي وفحص المتصفح والموبايل موثقة منفصلة في [TEST-RESULTS](TEST-RESULTS.md)؛ لا يعني نجاح التطوير إجراء اختبار تحميل أو اختبار اختراق خارجي أو نشر عام.
