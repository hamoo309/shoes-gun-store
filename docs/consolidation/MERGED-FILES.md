# تقرير توحيد الملفات

اعتمدت النسخة الأحدث work/shoes-gun-runtime بعد مقارنة محتوى 22 نسخة كاملة ونسختين جزئيتين و10 أرشيفات. فُحصت الطرق والـRoutes والاستيرادات والأدوات والمراجع وقت التشغيل؛ لم تظهر ميزة تجارية لازمة موجودة فقط في نسخة قديمة. لم تُستبدل ملفات أحدث بملفات قديمة بسبب الاسم.

| الملف/المجموعة | الإجراء |
| --- | --- |
| apps/web وapps/api وPrisma وMigrations | نقل أحدث المصدر إلى SHOES-GUN، مع الحفاظ على الأيقونات والفوتر وصور الألوان وترتيب الأقسام وحالات الطلب وتقوية الدخول |
| scripts/restore-transfer.mjs وRESTORE-FIRST.cmd وREADME-TRANSFER.md | دمج أحدث أدوات النقل التي كانت منفصلة في حزمة 23 أكتوبر؛ توضيح الاستعادة مقابل تشغيل المصدر المجهز |
| .gitattributes وتاريخ Git | حفظ ضبط النصوص وتاريخ المستودع وفهرسه؛ لا Commit ولا Push |
| package.json وpackage-lock.json | إبقاء إصدارات الحزم؛ نقل dotenv وpg إلى dependencies لأن التشغيل يحتاجهما، والإبقاء على deepmerge-ts override المطلوب لـPrisma |
| أوامر test وlint | جعل npm test آمنًا افتراضيًا، وإضافة فحص TypeScript للمتغيرات والاستيرادات غير المستخدمة وأوامر اختبارات معزولة واضحة |
| tests/isolated-qa.mjs واختبارا الدخول والشحن | إزالة المسارات والمنافذ التاريخية الثابتة، مع تحقق المسارات والـPG وملكية HTTP قبل الكتابة |
| scripts/prepare-assets.mjs | مصدر الصور أصبح وسيطًا صريحًا، ووجهات الإخراج مرتبطة بجذر هذا المشروع |
| ثلاثة Imports فقط | حذف PaymentStatus غير المستخدم من orders.ts، وFormEvent من CommerceViews.tsx، وProduct من store-provider.tsx |
| .gitignore و.dockerignore | استبعاد transfer وdump وملفات الكاش والاختبارات العامة المؤقتة والبيانات الخاصة |
| README ودليل التشغيل ومساحة العمل | اعتماد مسار رئيسي واحد وتعليمات نقل ونشر محدثة |
| open-prepared-runtime.mjs والمجلد المتداخل القديم | عدم نقل جسر التشغيل إلى نسخة خارجية أو التطبيق القديم المكرر إلى المشروع النهائي؛ محفوظان في الأرشيف |

أُعيد تثبيت الاعتماديات من الصفر داخل المشروع الجديد؛ لم تُنسخ node_modules ذات الوصلات المطلقة القديمة. مصدر الواجهة وتصميمها وبيانات المتجر محفوظة، والتغييرات البرمجية المحدودة أعلاه لا تعيد بناء المتجر من الصفر.
