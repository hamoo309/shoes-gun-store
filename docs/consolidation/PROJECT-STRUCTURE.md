# بنية المشروع المعتمد

~~~text
SHOES-GUN/
├── apps/
│   ├── api/
│   │   ├── src/                  API، الصلاحيات، الطلبات، المخزون، التقارير
│   │   ├── prisma/               Schema وMigrations وأداة الإعداد الاختيارية
│   │   └── dist/                 API المبنية اللازمة للتشغيل
│   └── web/
│       ├── app/                  صفحات المتجر والدفع والإدارة وRTL
│       ├── components/           المتجر ولوحة الإدارة والصور والسلة
│       ├── lib/                  الأنواع ومساعدات الواجهة
│       ├── public/               الخطوط والصور الافتراضية اللازمة
│       └── .next/                بناء Next.js اللازم للتشغيل
├── scripts/                      التشغيل والبناء والنسخ والنقل
├── tests/                        الاختبارات الآمنة والاختبارات المعزولة
├── docs/                         المميزات والنشر والنسخ والتقارير
├── storage/                      وسائط المتجر الخاصة بالجهاز، مستبعدة من Git
├── .local/postgres/              قاعدة الجهاز الدائمة، مستبعدة من Git
├── .env                          إعدادات المتجر الخاصة، مستبعدة من Git
├── node_modules/                 مكتبات مولدة لهذا المسار فقط
├── package.json / package-lock.json
├── START-SHOES-GUN.cmd           التشغيل المعتاد
└── RESTORE-FIRST.cmd             استعادة حزمة نقل جديدة فقط
~~~

الأرشيفات ونسخ الاسترجاع وبيئة QA وأدلة الصيانة الخاصة موجودة خارج هذا المجلد، في archive/consolidation-20261023. حزم التسليم الجديدة موجودة في outputs. ملف SHOES-GUN.code-workspace الموجود بجوار المشروع يفتح هذا الجذر وحده.

مجلد المشروع يحتوي خدمات متعددة منظمة؛ ليست هناك نسختا Frontend نشطتان. الصور العامة الافتراضية ونسخ الصور الأصلية في storage ليست بديلًا عن بعضها أو ملفات آمنة للحذف تلقائيًا.
